# Upstream

VargaMesh Core is derived from Bitcoin Core.

The project intentionally retains applicable upstream:

- copyright notices
- MIT license text
- third-party attribution
- technical provenance
- historical references
- inherited implementation history

VargaMesh-specific network, product and consensus development is maintained
in the VargaMesh repository.
