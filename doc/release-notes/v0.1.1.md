# VargaMesh Core v0.1.1

VargaMesh Core v0.1.1 is the first regular VargaMesh Mainnet release
following the initial v0.1.0 public pre-release.

## Changes

- Marks VargaMesh Core as a regular release build.
- Removes the pre-release runtime warning associated with development builds.
- Updates the public Core version from v0.1.0 to v0.1.1.
- Updates VargaMesh CLI user-agent documentation to v0.1.1.
- Uses the official VargaMesh Core repository as the public source reference.

## Network compatibility

There are no consensus or network-identity changes in this release.

Unchanged:

- VargaMesh Mainnet genesis block
- SHA-256d Proof of Work
- 120-second target block spacing
- AuxPoW activation and chain ID
- ASERT difficulty adjustment
- address formats
- wallet format
- P2P port
- RPC port
- existing blockchain history

No chain reset or migration is required.

Existing VargaMesh Mainnet nodes can continue using their current blockchain
data directories when upgrading to v0.1.1.

## Validation

The release source is built and tested before publication. The production
upgrade process additionally verifies existing-chain continuity, RPC
operation, mining template generation and absence of the former pre-release
runtime warning.

## Upgrade

Stop the existing VargaMesh Core node cleanly before replacing binaries.

Back up important wallet data before upgrading.

VargaMesh Core v0.1.1 uses the same Mainnet blockchain and wallet data as
v0.1.0.
