# Code of Conduct

VargaMesh welcomes technical discussion and contributions from people with
different backgrounds and levels of experience.

Project discussions should remain professional and focused on the technical
work.

Participants are expected to:

- communicate respectfully
- critique code and ideas rather than people
- provide reproducible technical evidence where practical
- avoid harassment, threats and personal attacks
- avoid publishing another person's private information
- respect coordinated handling of security vulnerabilities

Maintainers may moderate participation that repeatedly disrupts technical
collaboration.

Security vulnerabilities should be handled according to `SECURITY.md`.
